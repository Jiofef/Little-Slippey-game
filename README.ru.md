Репозиторий аркадной игры **Little Slippey**
Краткое описание: Уклоняйся от тонны летящих в тебя ракет. Тренируй реакцию, запоминай структуру карт и адаптируйся к постоянно меняющимся правилам на них.
![preview_readme_image.png](.assets/preview_readme_image.png)
---

Игра разработана на движке Godot для Desktop платформ 
Основная ветка HTML5-version носит историческое название, связанное с ранними планами по браузерной версии. В текущем виде игра ориентирована только на Desktop.

Игра выпущена в раннем доступе и находится в играбельном и проходимом состоянии. Доработка вторичного контента в проекте на данный момент заморожена из-за перераспределения времени на учёбу и другие проекты.

---

Ссылка на игру в Steam: https://store.steampowered.com/app/3288650/Little_Slippey/

Если вы хотите собрать игру из исходного кода или что-то в ней модифицировать, вам понадобится Godot Engine 4.4 и (опционально) редактор кода, например Visual Studio или VS Code с соответствующими расширениями для работы с Godot.
Чтобы открыть проект в Godot, просканируйте директорию, в которую вы переместили распакованную папку Little-Slippey-game-HTML5-version из архива. Проект должен появиться в списке.
